# ASDLC — схема процесса

Страница-визитка: одна схема процесса и короткое описание к ней.

**Agentic Software Development Life Cycle** — процесс, по которому я веду разработку.
Агенты делают работу, человек отвечает за намерение и приёмку. Состояние процесса лежит
в файлах репозитория: один тикет, одна рабочая копия, одна свежая сессия.

## Страницы

- **index.html** — схема процесса: выгрузка из редактора как есть, четыре контура, ссылки на файлы.
- **operations.html** — операционная карта: роли агентов и их модели, путь тикета, сигналы
  эскалации, пороги контекста, роутинг моделей.

## Файлы схемы

| Файл | Что это |
|---|---|
| `pipeline.bpmn` | схема в BPMN 2.0: 37 элементов, 18 связей, авторская раскладка |
| `pipeline-scheme.pdf` | та же схема одним листом, A4 альбомная |
| `pipeline-scheme.png` | то же картинкой, 2000 × 841 |
| `pipeline-editor.svg` | выгрузка из редактора со всеми плашками артефактов (1,9 МБ) |

Схема на странице — это `pipeline-editor.svg`: экспорт из редактора, у которого убран белый фон
пула и тёмная обводка заменена на светлую, чтобы читалось на тёмной странице. Геометрия, блоки,
подписи и плашки не менялись.

Бабочка — [ascii.rest](https://ascii.rest/butterfly/), MIT: один тег `<ascii-art piece="butterfly">`.
`print.html` — служебная страница, из неё пересобираются PDF и PNG.
